# 🚀 Installation

1. Clone the repository

```bash
git clone https://github.com/zeycookss/Weatherly.git
```

2. Open the project folder.

3. Create your own OpenWeather API key.

4. Replace the API key inside:

```javascript
const apiKey = "YOUR_API_KEY";
```

5. Open `index.html` using Live Server.
